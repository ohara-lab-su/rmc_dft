# rmc_vasp

## 準備
### VASP
### RMC

## install

Just download https://github.com/shimane-dev/sae/

If you have "aaa.cfg",
````
$ python ./sae/StructureAnalysisEnvironment/bin/Rcfg2vasp_nonLIB.py aaa
````
to get "aaa.vasp".

````
$ python ./Rvasp2cfg_nonLIB.py aaa
````
to regain "aaa.cfg"
