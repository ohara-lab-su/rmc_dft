`packmol_util` は、Packmol を利用したアモルファス初期構造作成を Python から扱うためのライブラリです。

組成、総原子数、密度、最小分離距離などの条件から、Packmol 入力の生成、Packmol の実行、生成構造の POSCAR 変換までを扱います。
