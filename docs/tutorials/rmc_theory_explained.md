# RMCとは
reverse Monte Carlo法
シミュレーティッド・アニーリングで、X線全散乱実験など、構造情報を反映したデータに、合うような原子配列を探索する。


# シミュレーティッド・アニーリング(焼きなまし法)
```{art}
ポテンシャルエネルギー（高）
|
|              ● ← 初期位置（高温）
|             / \   局所最小
|            /   \  ↓       
|           /     \     /\
|          /       \_●_/  \   
|         /                \
|      __/                  \__●_← 最低地点（グローバル最小）
|
ポテンシャルエネルギー（低）
```
