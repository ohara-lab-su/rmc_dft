# rmc_vasp

"rmc_dft" は第一原理分子動力学/構造最適化と逆モンテカルロ法 (RMC)交互実行をサポートするソフトです。 Structure Analysis
Environment package (
https://github.com/shimane-dev/sae.git )をベースにしています。

```aiignore
python setup.py install
```
