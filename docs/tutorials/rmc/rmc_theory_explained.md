# RMCとは
reverse Monte Carlo法

シミュレーティッド・アニーリングで、X線全散乱実験など、構造情報を反映したデータに、合うような原子配列を探索する。


# シミュレーティッド・アニーリング(焼きなまし法)
```{text}
ポテンシャルエネルギーE
↑
|
|              ● ← 初期位置（高温）
|             / \   局所最小
|            /   \  ↓       
|           /     \     /\
|          /       \_●_/  \   
|         /                \
|      __/                  \__●_← 最低地点（グローバル最小）
|
```


RMCPOT では

```math
\frac{E}{\sigma^2} = \chi_{new}^2 - \chi_{old}^2  \quad , \quad

\chi^2 =  \frac{(S(Q)_{calculation} - S(Q)_{experiment})^2 }{\sigma^2}
```
になっており、アニーリングのエネルギーに相当するのは実験との一致度　直接ではなく、現状の一致度の更新の度合い、になっているように思われる。
これは、探索がより局所的になるのかどうか・・・よくわからない。いずれにしても、アニーリングの温度パラメーター
σ^2 を指定することができる。

ここで、Eは、新しい試行がアクセプトされる確率Pとボルツマン因子を通した関係:
```math
P=\min[\exp(-E/\sigma^2),1]
```
にある量である。

正確な記述は公式
https://www.szfki.hu/~nphys/rmc++/RMC_POT_user_guide.pdf
の式4周辺を参照
